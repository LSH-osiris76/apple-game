## 아이콘

`tools/make_icons.py`로 직접 생성함. 실행 위치와 무관하게 항상 이 디렉터리(`assets/`)에 저장된다.

실행 방법:
```bash
python3 tools/make_icons.py
```

## 사용하지 않은 것

디즈니 『백설공주와 일곱 난쟁이』(1937)의 이미지는 저작권이 유효하므로 사용하지 않음.
