# 사과게임 — 시간제한 없음

사각형 안 숫자의 합이 10이면 사과가 사라지는 게임. 원작과 달리 시간제한이 없다.

**플레이: https://lsh-osiris76.github.io/apple-game/**

## 규칙

- 누르고 끌어 만든 사각형 안의 합이 정확히 10이면 사과가 사라진다
- 가로·세로 직선뿐 아니라 정사각형·직사각형 어떤 모양이든 된다
- 개수 제한은 없다. 두 개든 열 개든 합이 10이면 된다
- 이미 지워진 빈칸은 0으로 센다
- 힌트·되돌리기·섞기는 없다. 드래그 중에는 합계를 알려 주지 않는다
- 더 지울 조합이 없으면 끝난다

## 난이도

| 난이도 | 격자 | 대상 | 화면 |
|---|---|---|---|
| 하 | 8 × 6 | 7~10세 | 세로·가로 |
| 중 | 12 × 8 | 초등 고학년~중학교 | 세로·가로 |
| 상 | 17 × 10 | 고등학교~대학교 | 가로 전용 |
| 최상 | 20 × 12 | — | 가로 전용 |

숫자 분포도 함께 바뀐다. 하는 평균 5.0이라 두 개로 끝나고, 최상은 평균 3.2라 서너 개를 묶어야 한다.

## 폰에 설치

브라우저로 위 주소를 열고 **홈 화면에 추가**를 누른다. 아이콘이 생기고 전체화면으로 뜨며 오프라인에서도 동작한다.

## 개발

```bash
npm install
npm test          # 게임 로직 단위 테스트
npm run serve     # http://localhost:8000
```

`js/rules.js` · `js/board.js` · `js/layout.js`는 순수 함수만 담고 있어 테스트로 덮여 있다. DOM을 만지는 모듈은 브라우저에서 확인한다.
